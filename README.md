# WeChase Bank — Mini Project Website

## 🏦 Project Title
We Chase Bank — Your Trusted Partner Since 2007

---

## 🎯 Purpose of Website
This website represents a modern, professional banking platform for "We Chase Bank."
It is designed to provide customers with information about banking services, allow
them to explore products, and guide them through account registration — all in a
clean and trustworthy interface.

---

## 💻 Technologies Used
- HTML5 — Page structure and content
- CSS3 — Styling, animations, responsive layout
- JavaScript (Vanilla) — Interactivity, animations, modals, form logic

---

## ✨ Main Features
- Animated loading screen with progress bar
- Hero section with typewriter text effect
- Sticky navigation header with smooth scroll
- Interactive account registration demo modal
- Testimonials carousel with auto-rotate
- Services and products section
- Loan calculator / account types section
- Responsive mobile navigation (hamburger menu)
- Floating CTA button and Back-to-Top button
- Toast notification system
- Scroll-triggered animations (fade-in on scroll)

---

## 🔄 Website Flow / Working
1. User lands on the page → animated loader appears
2. Hero section loads with typewriter effect and trust stats
3. User can explore services via the navigation bar
4. "Watch Demo" button opens an interactive registration walkthrough
5. Testimonials auto-rotate to show customer reviews
6. User can click "Open Account" CTA to begin registration
7. Floating CTA appears after scrolling past the hero
8. Mobile users get a hamburger menu for easy navigation

---

## ✅ Conclusion
WeChase Bank Website is a complete, responsive, and visually professional
banking front-end built using only HTML, CSS, and JavaScript. It demonstrates
key web development skills including animations, DOM manipulation, modal
systems, responsive design, and interactive UI components.
